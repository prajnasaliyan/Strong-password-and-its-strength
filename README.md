# Strong-password-and-its-strength
📌 Objective

To understand what makes a password strong and evaluate different passwords using an online password strength checker.

🛠 Tools Used

Password Meter

Web Browser (Kali Linux / Windows)

🔎 Procedure
Step 1: Created Multiple Passwords

The following passwords were created with different complexity levels:

prajna123

Prajna@123

Cyber@2026

CyBer@2026$Secure

I_Love_Cyber$ecurity_2026!

Step 2: Tested Password Strength

Each password was tested using Password Meter and the results were recorded.

📊 Results
Password	Score	Strength Level	Feedback
prajna123	25%	Very Weak	No uppercase, predictable
Prajna@123	55%	Medium	Needs more length
Cyber@2026	70%	Strong	Good mix of characters
CyBer@2026$Secure	90%	Very Strong	Good complexity & length
I_Love_Cyber$ecurity_2026!	100%	Extremely Strong	Excellent password

(Scores may vary depending on tool evaluation)

🔐 Common Password Attacks
1️⃣ Brute Force Attack

An attacker tries all possible combinations until the correct password is found.

2️⃣ Dictionary Attack

An attacker uses a list of common words to guess the password.

3️⃣ Credential Stuffing

Using leaked username-password combinations from data breaches.

4️⃣ Phishing

Tricking users into revealing their passwords through fake emails or websites.

🔑 What Makes a Password Strong?

Minimum 12–16 characters

Combination of:

Uppercase letters

Lowercase letters

Numbers

Special symbols

Avoid personal information

Avoid common dictionary words

🛡 Importance of Password Length

Longer passwords increase the number of possible combinations, making them harder to crack using brute force attacks.

Example:

Weak: R@ndom9
Strong: MyDogRunsFast@Night2026!

🔐 What is Multi-Factor Authentication (MFA)?

Multi-Factor Authentication requires two or more verification methods, such as:

Password

OTP (One Time Password)

Fingerprint

Face recognition

This provides extra security even if the password is compromised.

💼 How Password Managers Help

Password managers:

Generate strong passwords

Store passwords securely

Prevent password reuse

❌ Common Mistakes in Password Creation

Using "123456"

Using name or date of birth

Reusing the same password

Creating short passwords

✅ Conclusion

This task helped in understanding how password length and complexity affect security. Strong passwords significantly reduce the risk of brute force and dictionary attacks. Passphrases with high complexity provide better protection than short simple passwords.
